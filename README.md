# Abismo

App web sobre el océano profundo, con Sonda, un bot de preguntas que funciona sin internet ni API key.

## Abrir en Kiro
1. Kiro: File > Open Folder y elige la carpeta `abismo`.
2. Abre `index.html` y usa la extensión Live Server, o ejecuta `npx serve .` en la terminal integrada.

## Ampliar el bot
Edita el arreglo `KB` en `app.js`: cada entrada tiene palabras clave (`k`) y una respuesta (`a`).
